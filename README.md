# order-quote

A Java 21 project. Clone this repository and start on `main`.

```sh
./mvnw test
./run.sh price=50.00 is_member=true
```

On Windows, use `mvnw.cmd test`. Maven downloads dependencies on the first run.
Use `./mvnw -o test` when dependencies are already cached.

The project calculates an order quote. Extend it as directed in the exercise.
